How to save Perplexity threads to Notion

Notion reads Markdown well, so the cleanest route from Perplexity to Notion is a Markdown file. You keep headings, lists, code blocks and the source links.

One thread

  1. Install Threadkeeper (free) and open the thread on perplexity.ai. It is saved automatically.
  2. Click the Threadkeeper button at the bottom right and choose Export Markdown.
  3. In Notion, click Import in the sidebar (or Settings), pick Text & Markdown and choose the file. You can also drag the .md file onto a Notion page.

Each question becomes a heading with its answer underneath, so a long thread with many follow-ups turns into one tidy Notion page.

Many threads at once (Pro)

  1. In the Threadkeeper library, tick the threads you want, or a whole folder.
  2. Export them as one ZIP of Markdown files (Pro, $19 once).
  3. Unzip, then import the files into Notion in one go. Each thread becomes its own page.
Why not copy and paste? Pasting a long answer usually drops the source links or mangles tables and code. A Markdown export keeps them.

FAQ

Can I import Perplexity into a Notion database?

Yes. Import the Markdown files into a page inside a database, or move the imported pages into one afterwards. Each thread becomes one page.

Does Threadkeeper connect to my Notion account?

No. It never logs in to Notion. It creates Markdown files on your computer, and you import them. Nothing is sent to any server.
