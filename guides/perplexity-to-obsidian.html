How to save Perplexity threads to Obsidian

Obsidian reads plain Markdown files, so getting Perplexity into your vault is a matter of exporting clean Markdown into the vault folder.

One thread

  1. Install Threadkeeper (free) and open the thread on Perplexity.
  2. Click the Threadkeeper button and choose Export Markdown.
  3. Save the file into your vault, for example Vault/Perplexity/.

Your whole library (Pro)

  1. Open the Threadkeeper library and tick the threads (or Select all).
  2. Export as ZIP. Each thread becomes one Markdown file inside a folder that matches its Threadkeeper folder.
  3. Unzip into your vault.

Bulk-exported files start with frontmatter (title, source link, folder, tags, date), so Obsidian's search, tags and Dataview work right away. Single-thread exports list the tags as #hashtags instead.

Does the export work with Dataview?

Yes. Bulk (Pro) exports include frontmatter (title, source, folder, tags, date) as standard YAML that Dataview can query.
