How to keep the sources when you save a Perplexity answer

The sources are half the value of a Perplexity answer. Copying the text into a note often turns them into bare numbers like [1] with nothing behind them. Here is how to keep them.

Save the whole thread with its links

  1. Install Threadkeeper (free) and open the thread on perplexity.ai.
  2. Choose Export Markdown from the Threadkeeper button. Each answer comes with its sources as clickable links.
  3. Paste or import the file wherever you keep notes: Obsidian, Notion, Google Docs or a plain folder.

Find the source again later

Threadkeeper keeps the full text of every saved thread and searches it, so you can find the answer, and its sources, from a word you remember. See how to find an old Perplexity answer.

Before you quote an answer: open the source link and check that it says what the answer claims. AI answers sometimes cite a page that only partly supports them.
