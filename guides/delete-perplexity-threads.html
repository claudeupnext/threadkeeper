How to delete Perplexity threads (and keep a copy first)

Cleaning up a crowded Perplexity library is quick. Undoing it is not: Perplexity's help center says a deleted thread cannot be retrieved. Here is how to delete threads, and how to keep the answers you might want later.

Delete a thread on Perplexity

  1. Open Library from the left sidebar on perplexity.ai.
  2. Click the three-dot menu next to the thread.
  3. Choose Delete Thread.

Perplexity's own FAQ says this is permanent, so treat it as final. Perplexity's menus change from time to time, so the wording may differ slightly.

Keep a copy before you delete (free)

  1. Install Threadkeeper from the Chrome Web Store.
  2. Open each thread you are about to delete. Threadkeeper saves it to your computer as you open it, with every question, answer and source link.
  3. Optional: file it into a folder such as Archive from the Threadkeeper button at the bottom right, or choose Export Markdown or Export PDF for a file you can keep anywhere. For long threads, leave Include the whole thread ticked so older messages are loaded first.
  4. Now delete the thread on Perplexity.

The saved copy stays in your Threadkeeper library. You can still search its full text and export it, even though the link back to Perplexity no longer works.

Keep the copy safe too

Threadkeeper stores everything in your browser's local storage, so it goes with that browser profile. Once in a while, open the library, go to Settings and click Download backup (.json). Restore backup brings it all back, on this or another computer. More in how to back up your Perplexity threads.

Be honest with yourself about one limit: Threadkeeper can only keep threads it saw. It cannot bring back a thread that was deleted before you opened it with Threadkeeper installed.

FAQ

Can I recover a deleted Perplexity thread?

Perplexity's help center says a deleted thread cannot be retrieved. If you had opened it with Threadkeeper installed, its saved copy is still in your Threadkeeper library.

Does deleting a thread in Threadkeeper delete it on Perplexity?

No. Deleting from the Threadkeeper library only removes the local copy. Your Perplexity account is not changed.

Does Threadkeeper delete Perplexity threads for me?

No. Threadkeeper never changes your Perplexity account. You delete threads on perplexity.ai yourself.
