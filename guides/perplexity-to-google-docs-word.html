How to get a Perplexity thread into Google Docs or Word

Perplexity can export a single answer as a DOCX file. For a whole thread with all its follow-up questions, export it as Markdown first, then bring it into Google Docs or Word.

A single answer

Under the answer on perplexity.ai, use Perplexity's own Export button and pick DOCX. That is enough for one answer.

A whole thread into Google Docs

  1. Install Threadkeeper (free), open the thread, click the Threadkeeper button and choose Export Markdown.
  2. In Google Docs, turn on Tools > Preferences > Enable Markdown.
  3. Open the .md file in any text editor, copy everything, and in a new Doc use Edit > Paste from Markdown. Headings, lists and links come through formatted.

A whole thread into Word

  1. Do the Google Docs steps above.
  2. In Google Docs, choose File > Download > Microsoft Word (.docx).

Prefer a fixed layout? Choose Export PDF in Threadkeeper instead. It opens a clean print view where you pick Save as PDF.

FAQ

Does Perplexity export to Word?

Perplexity's own export saves one answer as PDF, Markdown or DOCX. For a full thread in one document, export the thread to Markdown with Threadkeeper and convert it through Google Docs.

Are the source links kept?

Yes. The Markdown export keeps each answer's sources as links, and Google Docs keeps them when you paste from Markdown.
